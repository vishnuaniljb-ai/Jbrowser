# 🌐 JBrowser

**Fast, Private, and Secure Custom Web Browser for Android**

JBrowser is a high-performance, Chromium-based web browser engineered to deliver an uncompromised mobile web experience. Built from the ground up with a focus on extreme privacy, battery efficiency, and rich media tools, JBrowser gives you total control over how you explore the web.

---

## ✨ Key Features

### 🛡️ Unmatched Privacy & Security
* **Free Fast Privacy VPN:** High-speed built-in privacy tunnel for anonymous browsing.
* **Full VPN Suite:** Integrated country selector, DNS-over-HTTPS (DoH with Cloudflare & Google), and custom SOCKS5 proxy support.
* **Smart Ad & Popup Blocker:** Automatically intercepts and blocks intrusive popups, banners, and aggressive ad trackers.
* **Biometric App Lock & Password Vault:** Lock JBrowser natively with Fingerprint/Face ID and securely save your login credentials.
* **AES-256 Vault Encryption:** Hardware-backed binary file encryption for all items stored in your Private Vault.
* **100% Safe & Private:** Zero data collection, zero tracking, strictly respecting your privacy.

### ⚡ Extreme Performance
* **Hardware Acceleration & Native Cache:** Experience fluid 60fps hardware rendering and instant Back/Forward page navigation.
* **Battery & CPU Optimization:** Achieves aggressive efficiency with 0% background JavaScript CPU load on text pages.
* **Tab Memory Garbage Collection:** Automated cleanup of all WebView references and background timers when tabs are closed, preventing memory leaks and keeping your device fast.

### 📹 Media & Productivity Tools
* **Advanced Free Video Downloader:** Features a built-in per-video toolbar and a total webpage media scraper capable of supporting thousands of websites.
* **Real-Time Webpage Translator:** Seamless in-page and proxy translations across multiple languages.
* **Distraction-Free Reader Mode:** Clean, clutter-free article views with full table support, dynamic font scaling, and Sepia / Dark visual themes.
* **Advanced Download Manager:** Multi-threaded, parallel downloading engine with full resume support for interrupted files.
* **Print & Save as PDF:** Integrated wireless printing and 1-tap PDF conversion for preserving any web page offline.

### 🎨 Modern & Intuitive UI
* **Sleek Theming:** Beautiful, modern UI with deep integration for Light and Dark modes.
* **Live Find-in-Page Counter:** Dynamic "X of Y" match counter with easy navigation cycling for finding text quickly.
* **Intuitive Bookmark Manager:** Easily organize, sync, and access your favorite sites.

## 📥 Installation

You can download the latest stable APK directly from our Releases page.

1. Navigate to the **Releases** section of this repository.
2. Download the latest `JBrowser.apk` file.
3. If prompted by Android, allow your device to install apps from unknown sources (you may safely bypass standard Play Protect warnings for unlisted developer apps during sideloading).
4. Install and launch!
